# SWYNEX Security Fundamentals Assessment

## 1. Introduction

This report documents a security assessment performed against an intentionally vulnerable OWASP Juice Shop application running in an authorized local lab environment.

The assessment was performed using Kali Linux with Nmap, cURL, and OWASP ZAP.

The objective was to identify security weaknesses, collect evidence, assess their risk, and provide appropriate mitigation recommendations.
